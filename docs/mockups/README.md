# Maquettes (copie du canevas)

Copie des fichiers du canevas Design « Nova Preem — MVP » (https://claude.ai/artifact/EeVh5fSkMmUbTXN9fnKwXC), mise à jour le 29/10/2026 (Sets en quatre niveaux, saisie par − et +, Collection en galerie, vue 3D, synchronisation Google Drive).

- **La référence reste le canevas** : cette copie peut prendre du retard. En cas de différence, le canevas fait foi.
- `canvas.json` est l'index (titre de chaque planche, post-it) ; chaque `*.dc.html` est une planche.
- Ce sont des maquettes, pas du code à reprendre : données de démonstration (échantillon de 60 cartes, quantités fictives) et moteur propre à l'outil de design.
- Planches mobiles : `Main`, `SetReleases`, `SetGrid`, `CardDetail`, `CardViewer`, `Collection`, `Search`, `Completion`, `Settings`, `States`. Planches bureau : `WebSetList`, `WebSetReleases`, `WebSets`, `WebCard`, `WebCardViewer`, `WebCollection`, `WebSearch`, `WebStats`, `WebSettings`, `WebStates`.
- Synchronisation Google Drive (`docs/sync-spec.md` §8) : `SyncSettings` / `WebSyncSettings` (Réglages → Données, tous les états via le réglage « etat »), `SyncFirst` / `WebSyncFirst` (choix de la première synchronisation), `SyncIndicators` (pastille mobile, barre latérale bureau, bandeau de pause, tous les textes FR / EN).
