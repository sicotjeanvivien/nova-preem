# Maquettes (copie du canevas)

Copie des fichiers du canevas Design « Nova Preem — MVP » (https://claude.ai/artifact/EeVh5fSkMmUbTXN9fnKwXC), au 26/10/2026 (mise à jour : Sets en quatre niveaux, saisie par − et +).

- **La référence reste le canevas** : cette copie peut prendre du retard. En cas de différence, le canevas fait foi.
- `canvas.json` est l'index (titre de chaque planche, post-it) ; chaque `*.dc.html` est une planche.
- Ce sont des maquettes, pas du code à reprendre : données de démonstration (échantillon de 60 cartes, quantités fictives) et moteur propre à l'outil de design.
- Planches mobiles : `Main`, `SetReleases`, `SetGrid`, `CardDetail`, `Collection`, `Search`, `Completion`, `Settings`, `States`. Planches bureau : `WebSetList`, `WebSetReleases`, `WebSets`, `WebCard`, `WebCollection`, `WebSearch`, `WebStats`, `WebSettings`, `WebStates`.
